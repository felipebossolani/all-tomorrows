# Retomada no Linux

## Estado da entrega

Projeto em planejamento. Não há código de jogo, dependências instaladas, build,
servidor ou testes de aplicação. O desenvolvimento acontecerá na máquina Linux.

Repositório público: https://github.com/felipebossolani/all-tomorrows

## Baixar e abrir

Execute separadamente:

```bash
git clone https://github.com/felipebossolani/all-tomorrows.git
```

```bash
cd all-tomorrows
```

Abra essa pasta no ambiente usado para trabalhar com o agente.

## Contexto a preservar

Leia [PRD.md](PRD.md) e [RIGHTS.md](RIGHTS.md).
As alternativas estão em [IDEIAS.md](IDEIAS.md).

- A v0 é uma surpresa pronta antes do primeiro playtest.
- O jogador passa a colaborar após experimentar a primeira versão.
- São seis salas, quatro tipos de módulo e uma campanha com encerramento.
- A arte precisa ser fiel ao livro, sem intensificar o grotesco.
- Código/documentação original sob MIT; imagens e referências têm tratamento separado.
- Sem multiplayer, física contínua, backend ou editor de fases na v0.
- Interface em português brasileiro; alvo inicial é navegador desktop.
- A implementação ainda precisa ser solicitada na nova sessão.

## Ponto de partida quando a implementação for solicitada

Escolher uma toolchain mínima e registrar os comandos reais de setup, execução,
build e testes. Construir primeiro uma sala com montagem, movimento, pegar/entregar,
desfazer e reiniciar. Validar esse ciclo antes de expandir.

Preparar em paralelo ao desenvolvimento uma amostra visual referenciada para revisão
de Felipe; não envolver o jogador antes da surpresa.

A publicação de um site jogável ainda não foi feita; não há URL de jogo.
